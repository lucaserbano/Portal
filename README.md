# πύλη

Portal pessoal: quadros e tarefas, formulários, agenda e conteúdo para social media.

- `web/`: interface (SvelteKit estático, publicada no GitHub Pages)
- `api/`: backend (Cloudflare Worker + D1)

Nenhum dado pessoal fica neste repositório. Os dados vivem no Cloudflare D1, com backup diário num repositório privado.
